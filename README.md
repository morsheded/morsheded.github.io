# morsheded.github.io

Personal site — served by GitHub Pages at https://morsheded.github.io

Single static page, no build step. Edit `index.html` and push to `main`; Pages redeploys automatically.

## Before it goes live

Replace the two placeholders in `index.html`:

- `REPLACE_EMAIL` — contact address (appears twice, in the `mailto:` and the link text)
- `REPLACE_LINKEDIN` — LinkedIn profile slug

## Custom domain

Add a `CNAME` file containing the bare domain, then point a CNAME record at `morsheded.github.io`.
